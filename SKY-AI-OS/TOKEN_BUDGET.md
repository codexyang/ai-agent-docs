# TOKEN BUDGET

VERSION: SAOS v2.1

## Default Reply Budget

Target: 300 tokens unless the user asks for detail.

## Prohibited in Normal Reports

- Long background restatement.
- Repeating already-locked decisions.
- Re-listing the entire architecture.
- Repeating secrets or connection strings with passwords.

## Allowed

- Result.
- Error.
- Next step.
- Files changed.
- Database touched.
- Handoff.

## Human Execution Gate Output

When blocked by Prisma / build / Node engine limitations, output only:

- failed command
- exact command for human to run
- expected result to paste back
- what remains blocked until result is returned
