# Target Architecture

Version: SAOS v2.0

## Target

A stable, documented, multi-environment SKY Shopping platform where Agents can safely continue work without rediscovering architecture.

## Environments

- Production: live only.
- Backup: protected backup.
- Staging: integration validation.
- Development: feature work.
- DR-Test: restore drill and disaster recovery validation.

## Agent Operating Goal

Any new Agent should be able to become productive within five minutes by reading SAOS documents, not by scanning the repository.
